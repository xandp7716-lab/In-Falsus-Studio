# InFalsus Studio+ 1.06 源码节点

2026-10-25；内部整合插件版本 1.0.70，目标编辑器 Windows Mono 1.0.10。本 fork 现命名为 `infstudioplus`，保留上游来源及原始 Unity 工程。

- 原生视觉和现代界面集中在一个插件中；EXE 使用自由轮廓 M＋ 图标，设置页显示统一亮蓝 Q 版 Mei 描边图和 Fork 署名。
- 编辑流程包含镜像/批处理、快速 Timing 工具与 SkyArea 切分入口、可修改热键及鼠标侧键/中键绑定。
- 复制粘贴保留各物件原 SkyArea 组号、时间组及缺失组属性；端点拖移支持仅时间/仅位置两种模式。
- 预览、拖动提交、时间组及时序列表采用索引、缓存、虚拟化等优化；切窗后清理旧鼠标捕获和修饰键状态。
- 通用外置接口支持 SPC 文本及批量追加/替换/删除补丁，旧输出模式继续兼容。括号头隧道、任意 Flick/SkyArea 随机散布以可选工具源码保留。

**[非官方壳子 · InFalsus Studio Windows Mono 1.0.10 / inf-mod6 1.0.6 build 25797904]** 时间组、noinput/noclip/hidegroup 由插件提供，官方游戏不实现这些语义。安装插件为显式启用；保存仍保留扩展文本，不提供官方格式的静默转换。目标壳子未提供可定位公开源码/tag；游戏内判定和播放未验证。详见 [兼容性](../../Mods/InFalsusStudioPlus/1.06/COMPATIBILITY.md)。

本次提交仅收录源码、作者性图形、构建/图标工具和说明，不包含已编译程序、依赖、提取资源、缓存、个人谱面或整合包。验证边界见 [记录](../../Mods/InFalsusStudioPlus/1.06/VALIDATION.md)。
