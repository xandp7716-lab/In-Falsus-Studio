# 外置工具编写指南

把工具放在 `ExternalTools/工具ID/`，点击重载。文件夹名与 ID 一致：以英文字母开头，只含字母、数字、下划线。脚本与 `tool.json` 同目录。勿直接改工作谱。

## 最小示例

`ExternalTools/MyTool/tool.json`：
```json
{"version":1,"id":"MyTool","name":"添加时序","nameEn":"Add track","script":"Tool.ps1","output":"spc","fields":[{"key":"time","label":"时间","labelEn":"Time","type":"time","defaultValue":"1000"}]}
```
`Tool.ps1`：
```powershell
param($RequestPath, $OutputPath)
$ErrorActionPreference = 'Stop'
$r = Get-Content -LiteralPath $RequestPath -Raw -Encoding UTF8 | ConvertFrom-Json
$t = [int](($r.values | Where-Object key -eq 'time').value)
[IO.File]::WriteAllText($OutputPath, "track($t,1)`n", [Text.UTF8Encoding]::new($false))
```
运行后向目标时间组追加 `track(1000,1)`。结果经校验后一次撤销；Ctrl+S 才保存。

## 清单和调用

必须有 version=1、id、name、nameEn、同目录的 .ps1 script、output="spc" 和 fields 数组。字段最多 30 个，key 唯一且遵循 ID 字符规则；类型为 time、integer、number、text、file、bool、choice。time 为 0～86400000 整数毫秒；choice 的 options 必须包含 defaultValue。值以字符串传入，请按固定小数点格式解析。

可选 selection、capture、gridField、groupMode 等字段见 `PROTOCOL.md`。扩展播放取决于目标壳子。

PowerShell 接收 `-RequestPath` 与 `-OutputPath`，工作目录是工具目录。成功返回 0；失败写 stderr 并非零退出。结果写 OutputPath，stdout 是日志；支持 UTF-8 与空格路径。

## 请求与输出

请求包含 document、hasBom、rows、selection、capture、currentTime、currentGroup、targetGroup、range、values 等。rows 的 sourceId 是当前文档会话标识，不是行号，不能跨工程缓存；source 和 tokens 保留原行及参数。替换前须核对当前 rows。

声明 gridField 后，gridGroup/gridDivision 和网格来自主界面当前时间组及细分；skySources[].grid 含该 Sky 起点及其范围内网格，单条最多 4096 点。数量模式不提供网格；通用范围网格最多 10000 点。

输出普通 SPC 文本时追加到目标组。需要修改已有行时输出 JSON：
```json
{"version":1,"operations":[{"action":"replace","sourceId":12,"expected":"track(100,1)","text":"track(100,2)"},{"action":"append","scope":"$target","lines":["track(200,1)"]}]}
```
操作支持 append、replace、delete；替换/删除取当前 rows 的 sourceId，同一源行每批只能修改一次。expected 可核对原行；scope 空字符串指基础组，null 表示按完整原文追加，指定组名或 $target 可写入对应组。未知语句可保留，不代表具备预览或本体支持。

输出上限 8,000,000 字节、64000 条操作或变更行，超时 120 秒。执行期间谱面或网格改变会取消结果。可另写 `OutputPath + ".info.json"`，包含 message 和 segments 作为摘要；摘要不能代替输出。校验通过才提交，失败不会部分修改谱面。
