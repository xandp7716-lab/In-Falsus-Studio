# 随机散布工具

保留旧目录和 ID BlacklinePatternScatter，以兼容原有参数存储；界面改名为“随机散布工具”。先选中并捕获 1～256 个 Flick / SkyArea，可混选，可包含宽紫条、曲线及超界物件。每次散布复制整份捕获图案，保持内部相对时间和位置。

只平移时间与 X，不缩放、不抽样成折线、不转成 1 宽黑线、不加入藏头辅助段。宽度、左右缓动、持续时间、Flick 方向、注释及额外参数保留。坐标平移必要时等价扩展整数分母，保持几何比例精确；显式 SkyArea groupid 在每份副本内保持对应关系，并分配新组号避免与原物件或其他副本冲突。

保留起止时间、X 范围、份数、最小间距、种子与新建 noinput 选项。X 范围约束整份图案的左右边缘。旧 X 缩放选项移除。最小间距大于 0 时限制图案之间的时间间隔；等于 0 时避免图案 X/T 包围盒重叠。空间不足报告实际份数。默认新建 noinput 组；关闭时要求当前组为 noinput / noclip。

旧版 pattern.json 仅有采样中心线，无法还原宽度、曲线或 Flick，须重新捕获一次。安装不会删除或覆盖该缓存。一次撤销整批结果，手动保存。

使用通用 output: spc 和 captureKind: air，不依赖插件识别本工具 ID。timinggroup / noinput 为非官方壳子扩展。
