# 括号头隧道

选择 1～256 根有效 SkyArea 后执行。网格模式沿用每条紫条所在时间组的节拍网格（含组内 BPM 变化）；个数模式独立等分每根紫条的持续时间。includeEnd 开启时 count 至少 2。全部取点四舍五入为整数 ms 后去重。

每个括号由一条指定时长（`durationMs`，默认 1ms，范围 1～300000ms）的 SkyArea 表示，左右边缘按原紫条自身缓动采样，坐标最多 128 份。follow 在该单条时长内跟随原轨迹（超出原终点时夹紧到原终点坐标），flat 保持头尾同形。零宽点跳过，边缘交叉或超限则整批失败。终点物件可延长至原终点后 `durationMs`。单批最多 16000 个。

每个头使用独立 groupid，所有源合并按时间及 SourceId 排序后递增分配。新建 noinput 组默认开启；关闭时当前组须为 noinput / noclip。删除原紫条默认关闭，开启后与生成同属一次撤销。计算物件数不会插入、建组或删除源。

使用通用 output: spc 协议，未在插件中加入本工具 ID 的专属生成或校验分支。Tool.ps1 可用 -RequestPath / -OutputPath 独立运行，不需要 Python。

兼容性：timinggroup / noinput 是已支持的非官方壳子扩展，不是官方本体语法；游戏加载链路须支持它。1ms 主体在游戏里的实际可见程度仍需按流速与壳子确认，不生成 0ms SkyArea。
